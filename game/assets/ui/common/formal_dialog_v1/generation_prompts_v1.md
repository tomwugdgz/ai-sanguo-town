# Formal dialog v1 generation prompts

Built-in ImageGen was used with the current common feedback panel, formal pause menu, and new-game overwrite screen as visual references.

## Warning confirmation preview

Create a complete 1920x1080 in-game modal preview over a darkened pixel-town background. Use a warm parchment panel, walnut frame, restrained terracotta roof ornament, warning medallion, two lines of body copy, and pale-cancel plus terracotta-destructive buttons. Avoid Godot default styling, flat vector rectangles, debug outlines, and foliage inside text areas.

## Error retry preview

Preserve the warning preview geometry and replace only its semantic state: terracotta-red error medallion, error title and copy, pale close button, and terracotta retry button.

## Resident-memory input preview

Preserve the shared modal family and show a calm open-book emblem, a resident-memory title, one empty multiline parchment input surface, and cancel/confirm buttons.

## Runtime assets

Generate the dialog panel, multiline input surface, and open-book icon separately on a uniform green chroma-key background. Keep them textless, front-facing, crisp pixel art, and free of exterior shadows. Remove the chroma key locally with a soft matte, despill, and one-pixel edge contraction where needed.
