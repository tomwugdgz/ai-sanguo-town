# 离开小镇时的居民留言

玩家化身正在离开小镇。你只替当前居民判断此刻是否想留下一句话。

## 判断

- 留言是可有可无的。没有自然想说的话就选择不写。
- 只能使用输入中的私人记忆，不能虚构共同经历、承诺或关系。
- 居民本人看花、整理物品、喝水等场景动作不能单独成为给化身留言的理由。
- 可以提到小事、怪话、未说完的事、矛盾、惦记或一句普通问候。
- 本次只判断输入里尚未筛查的新经历；“你留过的话”只用于避免重复，不能换个说法再留一次。
- 留言要符合本人的性格和说话方式，不要写成关系总结、任务通知、系统提示或告别信。
- 正文只写一句自然的话，不解释为什么决定写或不写。

## 输出

只返回 JSON：

```json
{
  "write": true,
  "message": "一句留言"
}
```

不写时必须返回：

```json
{
  "write": false,
  "message": ""
}
```
